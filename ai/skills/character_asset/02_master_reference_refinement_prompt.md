# STEP 2 — Master Reference 2차 보정 프롬프트

## 목적

STEP 1에서 나온 Species 기본형을 **새로 디자인하지 않고**, 게임 자산 제작 기준으로 다듬는다.

목표:
- 캐릭터 identity 유지
- 4방향 일관성 강화
- top-down 2.5D 시점 보정
- 지나친 디테일 단순화
- 이후 Game-ready Sheet의 기준 확정

---

## 사용 전 조건

반드시 STEP 1 결과 이미지를 같이 첨부한다.

---

## 프롬프트

```text
첨부한 [캐릭터 별 내용 수정: 동물 종 이름] 기준 디자인을 바탕으로 수정본을 만들어줘.

이전 결과는 해당 Species 기본형 reference sheet 초안이다.
이번 작업의 목적은 새 캐릭터를 다시 만드는 것이 아니라,
기존 캐릭터 identity를 유지하면서 실제 게임용 기준 디자인으로 정리하는 것이다.

[반드시 유지]
- 동일한 캐릭터 identity
- 현재 확정된 체형
- 현재 얼굴의 기본 형태
- Species 고유 특징
- 현재 기본 의상
- top-down 2.5D pixel-art 방향
- Down / Left / Right / Up 4방향 구성

[이번 수정에서 반영할 피드백]
- [캐릭터 별 내용 수정: 1차 결과에서 수정하고 싶은 내용 1]
- [캐릭터 별 내용 수정: 수정 내용 2]
- [캐릭터 별 내용 수정: 수정 내용 3]
- [캐릭터 별 내용 수정: 필요 시 추가]

피드백이 없는 부분은 임의로 변경하지 마.

[게임 시점 보정]
- 일반 character turnaround보다 실제 orthogonal top-down 2.5D 게임에 맞게 보정
- Down에서 머리 윗부분과 어깨 상단이 아주 조금 느껴지게
- Up에서 머리 뒤쪽 윗면과 등/어깨 상단이 자연스럽게 보이게
- Left / Right에서도 머리와 어깨 상단 면이 아주 약간 느껴지게
- 극단적인 bird's-eye view로 만들지 말 것

[4방향 일관성]
- 머리 크기
- 몸통 길이
- 다리 길이
- 전체 체격
- Species 고유 특징
- 캐릭터의 전반적인 화면 크기
를 최대한 일관되게 유지

Left / Right는 가능한 한 동일한 구조와 비율 유지

[픽셀아트 단순화]
작은 게임 화면에서 읽히기 어려운 지나친 디테일은 줄여줘.

예:
- 과도한 근육 음영
- 의상의 세밀한 주름
- 작은 털 음영
- 복잡한 얼굴 명암
- 불필요하게 많은 작은 무늬

단, Species를 한눈에 알아볼 수 있는 대표 특징은 유지한다.

[친근감]
- 초등학생 대상 게임의 일반 주민 캐릭터로 사용할 수 있어야 함
- 지나치게 공격적이지 않은 neutral하고 편안한 표정
- 너무 유아틱한 chibi로 바꾸지는 말 것

[출력]
동일 캐릭터의 수정된 4방향 기준 디자인 시트:
1. Down
2. Left
3. Right
4. Up

[이번 단계에서 만들지 말 것]
- Idle
- Walk
- Run
- Talk
- Interact
- Special Action
- 다른 의상 variation
- 다른 Species

이번 결과물은 해당 Species의 Master Reference가 된다.
```

---

## 이 단계에서 확인할 것

- 캐릭터 identity가 유지되었는가
- 4방향이 같은 캐릭터로 보이는가
- side / front / back 체격 차이가 과하지 않은가
- 게임 화면에서 읽기 쉬운가
- 이후 애니메이션 기준으로 사용할 수 있는가
