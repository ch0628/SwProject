# STEP 1 — Species Master Reference 1차 생성 프롬프트

## 목적

새 Species의 **기준 캐릭터 디자인**을 만든다.

이 단계에서는 최종 게임 Sprite나 Animation을 만들지 않는다.

목표:
- Species의 기본 체형 확정
- 얼굴/귀/꼬리/무늬 등 종 특성 확정
- 기본 의상 확정
- Down / Left / Right / Up 4방향에서 같은 캐릭터로 보이는지 확인
- 이후 모든 Sprite/Animation의 Master Reference 확보

---

## 사용 방법

아래에서 `[캐릭터 별 내용 수정]` 부분만 해당 Species에 맞게 변경한다.

---

## 프롬프트

```text
SWfestival 웹 게임용 [캐릭터 별 내용 수정: 동물 종 이름] 캐릭터의 기준 디자인 reference sheet를 만들어줘.

이 이미지는 최종 일러스트가 아니라, 이후 게임용 sprite와 animation 제작에 사용할
"[캐릭터 별 내용 수정: 동물 종 이름] 종족 기본형 기준 디자인"이다.

[프로젝트 배경]
- 초등학생들이 AI를 쉽고 재미있게 배우는 게이미피케이션 웹 프로젝트
- 동물들이 살아가는 밝고 친근한 마을/도시 세계관
- 캐릭터는 시민, 수상한 인물, 악당 등 다양한 역할로 재사용될 수 있어야 함
- 현재 목적은 [캐릭터 별 내용 수정: 동물 종 이름] 종족의 기본형을 확정하는 것

[고정 스타일]
- top-down 2.5D
- pixel-art 기반
- PC 웹 게임용 캐릭터 디자인
- 귀엽고 친근하며 명확한 실루엣
- 너무 사실적이지 않음
- 초등학생 대상이라 읽기 쉽고 한눈에 구분 가능해야 함

[비주얼 레퍼런스 방향]
다음 작품들의 느낌과 장점만 참고해줘.
그대로 복제하지 말고 새로운 독립 캐릭터로 만들어줘.

- Zootopia:
  다양한 동물이 함께 살아가는 현대적 동물 도시의 친근한 분위기,
  밝고 생동감 있는 색감

- Elemental:
  따뜻하고 선명한 도시 감성,
  부드럽고 매력적인 색 구성

- Back to the Dawn:
  동물 의인화 캐릭터의 개성 있고 또렷한 실루엣,
  도시형 동물 캐릭터 감성

- Stardew Valley:
  top-down 게임 화면에서 읽기 쉬운 단순한 구성과
  맵 친화적인 캐릭터 구조

[캐릭터 설명]
- 의인화된 [캐릭터 별 내용 수정: 동물 종 이름]
- 일반 주민으로도 사용할 수 있는 기본형
- [캐릭터 별 내용 수정: 원하는 체형/키/체격]
- [캐릭터 별 내용 수정: 종을 알아볼 수 있는 핵심 특징]
- [캐릭터 별 내용 수정: 표정/성격 인상]
- 도시에서 살아가는 동물 주민 느낌
- 이후 의상, 가방, 장비를 추가할 수 있도록 기본 실루엣은 단순하게 유지

[기본 의상]
- [캐릭터 별 내용 수정: 기본 상의. 기본 추천 = 장식 없는 밝은 off-white 반팔 티셔츠]
- [캐릭터 별 내용 수정: 기본 하의. 기본 추천 = 짙은 charcoal 계열 바지]
- 로고, 복잡한 장식, 과도한 액세서리는 넣지 말 것
- 이 의상은 추후 모듈형 의상을 덧입히기 위한 neutral base outfit이다.

[출력 형식]
동일한 한 캐릭터를 4방향 기준 디자인 시트 형태로 보여줘.

반드시:
1. Down — 플레이어를 바라보는 방향
2. Left
3. Right
4. Up — 뒷모습

[중요 조건]
- 4방향 모두 완전히 같은 캐릭터처럼 보여야 함
- 머리 크기, 몸통 비율, 종 고유 무늬, 꼬리, 귀, 색감이 일관되어야 함
- 방향마다 새로운 캐릭터처럼 재해석하지 말 것
- 실제 top-down 2.5D 게임에서 사용할 수 있도록 아주 약간 위에서 내려다보는 느낌
- 게임용 기준 디자인 시트처럼 정리
- 배경은 단순하거나 없음
- animation frame은 아직 만들지 말 것

[피해야 할 것]
- 지나치게 사실적인 동물
- 무섭고 공격적인 표정
- 지나치게 세밀한 렌더링
- 복잡한 패션 코디
- 과장된 액션 포즈
- 일반 일러스트나 캐릭터 컨셉아트에만 적합하고 게임에 쓰기 어려운 시점
```

## 이 단계에서 만들지 않는 것

- Idle
- Walk
- Run
- Talk
- Interact
- Reaction
- Special Action
- Outfit variation
- 실제 게임용 crop
