# Skill: Implement Feature

## 사용 시점
이미 설계가 확정된 기능을 구현할 때 사용한다.

## 절차
1. `ai/RULES.md` 확인
2. `ai/CONTEXT_MAP.md`에서 필요한 문서만 선택
3. 관련 코드 확인
4. 구현 계획을 3~7개 단계로 짧게 정리
5. 미확정 핵심 설계가 있으면 구현 중단 후 사용자에게 질문
6. 구현
7. typecheck / lint / build
8. 필요한 테스트 실행
9. 변경사항 보고

## 금지
- 요청 범위를 넘어서는 기능 추가
- 사전 승인 없는 대규모 리팩터링
- 임의의 UX 변경
- spec과 다른 동작을 "개선"이라는 이유로 적용
