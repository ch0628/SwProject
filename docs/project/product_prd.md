## **1. 서비스 개요**

### **1.1 서비스 한 줄 정의**

> AI 마을을 탐험하며 게이미피케이션 요소를 통해 AI의 핵심 개념을 배우고, 다양한 문제를 해결하며 AI를 이해하는 초등학생 대상 AI 학습 서비스

### **1.2 문제 정의**

초등학생에게 AI는 점점 익숙한 기술이 되고 있지만, AI의 개념과 원리를 **추상적인 설명만으로 이해하기 어렵고,** 실제 생활에서 접하는 다양한 기술 중 무엇이 AI인지 구분하기도 어렵다.

또한 AI 교육이 개념이나 용어를 설명하는 방식으로 구성될 경우, 학습자가 내용을 수동적으로 받아들이는 데 그칠 수 있다.

따라서 AI의 핵심 개념을 **게임의 목표와 플레이 과정에 자연스럽게 녹여** 학습자가 직접 탐색하고 문제를 해결하면서 AI를 이해할 수 있는 교육 서비스가 필요하다.

### **1.3 서비스 목표**

초등학생이 AI를 어렵고 추상적인 기술로 받아들이는 것이 아니라, 직접 플레이하고 경험하면서 AI의 핵심 개념을 자연스럽게 이해하도록 하는 것을 목표로 한다.

### **1.4 핵심 가치 제안**

| 핵심 가치 | 내용 |
| --- | --- |
| 게임을 통한 자연스러운 학습 | 각 AI 개념을 단순한 설명이나 퀴즈가 아닌 서로 다른 게임 콘텐츠로 구성하여 학습 자체가 플레이 경험이 되도록 한다. |
| AI 개념을 단계적으로 학습 | AI를 하나의 큰 개념으로 설명하는 것이 아니라 세부 영역으로 나누어 단계적으로 학습하도록 한다. |
| 학습의 재미와 몰입 제공 | 탐험, 퀴즈, 선택, 장치 작동 등 다양한 활동에 학습 내용을 자연스럽게 연결한다. |

#### **2.1.3 플레이 구조**

| 항목 | 내용 |

| 카드 발견 | 실제 카드 면 대신 짧은 floor line + sparkle, 근접 시 `Q` + pulse |
| 카드 확인 | `Q` 획득 후 처음 앞면 확인. HUD 클릭으로 재확인 |

| 퀴즈 | 3문제, 이때만 하트 3개 |

| 퀴즈 성공 후 | 카드 6장의 앞면 중 AI 특징 3장을 직접 선택 |
| 카드 삽입 | 올바른 3장을 선택하면 뒷면으로 장치에 1→2→3장 삽입 |
| 장치 | empty → 1 → 2 → 3 → final activated |
| 복구 1 | 실내 조명 먼저 ON |
| 복구 2 | monitor / console / control system ON |
| 완료 | Ari가 AI와 단순 기계의 차이를 짧게 복기 후 완료 |

#### **2.1.4 카드 시스템**

6장 모두 동일한:
- front frame
- back
- size
- shape
- color

를 사용한다.

AI / 기계를 색상, 라벨, disabled 상태로 미리 알려주지 않는다.
유형은 **앞면 내용**으로만 판단한다.

##### AI 특징 카드 3장

1. **데이터를 학습해요**  
   AI는 사람이 하나하나 규칙을 알려주지 않아도, 많은 데이터를 보면서 필요한 정보를 배울 수 있어요.

2. **패턴을 찾아요**  
   AI는 여러 데이터를 살펴보면서 반복해서 나타나는 공통점이나 규칙을 찾아낼 수 있어요.

3. **스스로 판단해요**  
   학습한 내용을 바탕으로 새로운 상황을 살펴보고, 알맞은 답이나 행동을 판단할 수 있어요.

##### 단순 기계 특징 카드 3장

4. **같은 설정이면 같은 결과만 내요**  
   기계는 미리 정해 둔 설정이나 입력이 같으면, 보통 늘 같은 방식으로 작동해요.

5. **뜻을 이해하지 않고 신호에 반응해요**  
   기계는 들어온 신호나 명령에 반응할 수는 있지만, 말이나 상황의 뜻을 스스로 이해하는 것은 아니에요.

6. **스스로 구별 기준을 만들지 못해요**  
   기계는 여러 예시를 보고 공통점을 찾아 스스로 기준을 배우는 것이 아니라, 정해진 방식대로만 작동해요.

기계 카드는 최종 퀴즈의 상황을 직접 복사하지 않고 정답을 유추할 수 있는 특징만 제공한다.

#### **2.1.5 최종 퀴즈 3개**

**퀴즈 1)**

버튼을 누르면 정해진 시간 동안 작동하고, 시간이 지나면 자동으로 꺼지는 전등이 있어요.

이 전등은 AI일까요?

**① O ② X**  
정답: **X**

해설: 정해진 규칙에 따라 자동으로 작동하는 것만으로는 AI라고 할 수 없어요. AI는 데이터를 학습하고 그 내용을 바탕으로 판단하거나 예측할 수 있어요.

---

**퀴즈 2)**

AI에게 강아지와 고양이 사진을 여러 장 보여주었어요.

AI는 사진에서 반복되는 특징을 학습한 뒤, 처음 보는 사진이 강아지인지 고양이인지 판단했어요.

이것은 AI를 사용한 사례일까요?

**① O ② X**  
정답: **O**

해설: 많은 데이터를 학습하고, 그 안에서 특징과 패턴을 찾아 새로운 데이터를 판단했기 때문에 AI를 사용한 사례예요.

---

**퀴즈 3)**

다음 중 AI를 사용하고 있는 것은 무엇일까요?

① **엘리베이터**가 버튼을 누른 층으로 이동한다.  
② **로봇청소기**가 정해진 시간에 작동하여 집 안을 청소한다.  
③ **스피커**가 사람의 말을 듣고 질문의 내용을 파악하여 알맞은 답을 한다.

정답: **③**

해설: ①과 ②는 미리 정해진 규칙에 따라 작동할 수 있지만, ③은 사람의 말을 분석하고 학습한 내용을 바탕으로 질문의 의미를 파악하여 답을 만들어내므로 AI를 활용한 사례이다.


`[도전하기]` → 하트 3개 → 퀴즈.

#### **2.1.7 카드 선택 / 삽입 / 전원 복구**

1. 퀴즈 통과
2. 카드 앞면 6장 표시
3. 사용자가 AI 특징 카드라고 생각하는 3장 선택
4. 3장 미만 → warning
5. 잘못된 조합 → 다시 선택
6. 정답 3장 → 카드 뒷면으로 전환
7. device: empty → 1 → 2 → 3 → final activated
8. Stage 1: 실내 조명 ON, system 대부분 OFF
9. Stage 2: monitor / console / control system ON
10. Ari 핵심 복기
11. Complete

#### **2.1.9 시각 / 구현 원칙**

- dark room은 공포/시야 제한 gameplay가 아니라 분위기 연출
- 움직이거나 사라지는 object는 background pixel에 박지 않음
- 카드 발견은 floor line + sparkle
- card front 교육 text는 React UI text
- final device는 3F 오른쪽 final zone에 존재
- 실제 삽입은 close-up state sequence
- Power Stage 1 / 2는 dark map과 동일 구조 유지
